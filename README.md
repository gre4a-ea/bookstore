РУКОВОДСТВО ПО ЗАПУСКУ ПРОЕКТА "BOOKSTORE"



Создайте базу данных (название по умолчанию — bookstore):
   CREATE DATABASE bookstore CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;


Создайте пользователя или используйте root. Если вы хотите использовать
учётные данные root / sa, убедитесь, что пароль root в MySQL — "sa" (либо измените на свой в src/main/resources/META-INF/context.xml).


Для импорта начальных данных выполните SQL-скрипт, который находится в
проекте: src/main/resources/db/bs_init.sql. Я ЭТО СДЕЛАЛ ДЛЯ СВОЕГО УДОБСТВА, ОСТАЛЬНЫЕ СКРИПТЫ ЗАПУСКАТЬ НЕ НАДО. И БЭКАП не забудьте.


В файле src/main/resources/META-INF/context.xml указан JNDI-ресурс для
подключения к базе. По умолчанию настроено:
   username = root
   password = sa
   url = jdbc:mysql://localhost:3306/bookstore?useSSL=false...

Далее собираете с помощью Maven и запускаете в Tomcat. 

Входите по учетке из sql файла. Обычно это: email: user@example.com / пароль: user123 или admin@example.com / admin123 (если есть админка).
Далее я попросил Deepseek выполнить дебаг, чтобы вам пришлось писать меньше промта :D






--------------------------------------------------------
ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
--------------------------------------------------------

* Ошибка подключения к базе данных «Access denied for user...»
  Проверьте правильность логина и пароля в context.xml.
  Убедитесь, что база bookstore создана и доступна.

* Приложение разворачивается, но страницы не открываются (ошибка 500, stacktrace)
  a) класс JDBC-драйвера не найден — проверьте, что в pom.xml есть зависимость
     mysql-connector-java.
  b) проблема с кодировкой БД — убедитесь, что база в utf8mb4.

* Tomcat не запускается или порт занят
  Закройте все программы, использующие порт 8080, или измените порт Tomcat
  в файле conf/server.xml (поменяйте Connector port="8080" на другой).

* Не отображаются CSS / JS
  Возможно, контекст приложения задан иначе, чем /bookstore.
  Проверьте имя WAR-файла и URL.
